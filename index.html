Laboratorio Cero · Misión de recuperación

Recuperá el informe.

El sistema del laboratorio perdió la estructura del informe. Vos sos el agente de recuperación. Tu misión: restaurar el título principal y el párrafo usando solo dos etiquetas de HTML. Cada acierto suma puntos de integridad al sistema.

Nivel inicial · 15–20 minutos · Conocimientos previos: lectura y escritura básica · No se necesita saber programar

Tu objetivo

Al terminar vas a poder escribir un título principal y un párrafo con HTML usando <h1> y <p> con sus etiquetas de cierre.

Recorrido de la misión: primero aprendé las dos etiquetas; después resolvé tres retos de recuperación; al final comprobá que el informe quedó estable.

Dos etiquetas para ordenar el texto

HTML permite organizar el contenido de una página web. Una etiqueta indica qué función tiene cada parte del texto.

El título principal

El título principal presenta el tema de la página.

Usá <h1> al comienzo y </h1> al final.

<h1>Mi laboratorio</h1>

El párrafo

El párrafo desarrolla una idea con una o más oraciones.

Usá <p> al comienzo y </p> al final.

<p>El equipo funciona.</p>

La barra / marca el cierre. El texto se escribe entre la etiqueta de apertura y la de cierre. Al abrir la página, el navegador muestra el título y el párrafo sin las etiquetas.

Así se escribe el informe completo

<h1>Mi laboratorio</h1>
<p>El equipo funciona.</p>
